# **App Name**: Heovose Elevate

## Core Features:

- Multilingual Content Toggle: Seamlessly switch all content between English (primary) and Chinese (secondary) languages for global reach.
- Dynamic Hero Section: Display bold, left-aligned English headlines with Chinese subtitles alongside a striking right-aligned 45-degree perspective 3D product image.
- Interactive Product Gallery: Showcase various product categories including AIO, Mini PCs, Monitors, and KIOSKs with high-quality visuals.
- Core Statistics Visualization: Present key company statistics like '3 Global Factories in China/Indonesia' and '30+ AIO Series' in an engaging visual format.
- Animated Production Process Guide: Illustrate the detailed 11-step production logic (IQC, IPQC, OQA) with smooth, easy-to-understand animations.
- Global Presence Map: An interactive world map highlighting the factory locations in China and Indonesia, emphasizing Heovose's global footprint.
- Responsive Design System: Ensure a pixel-perfect, adaptive user experience across all devices, from mobile phones to large desktop displays.

## Style Guidelines:

- Primary brand color: A deep, professional blue (#36578D) to convey trust, technology, and corporate stability. Based on HSL(220, 40%, 35%).
- Background color: An ethereal off-white with a subtle blue tint (#F7F9FB) to complement the primary and emphasize 'Apple-style' whitespace. Based on HSL(220, 15%, 97%).
- Accent color: A sophisticated purple (#5F33CC) for interactive elements and highlights, providing an elevated contrast. Based on HSL(250, 60%, 50%).
- Headlines font: 'Space Grotesk' (sans-serif) for a modern, tech-savvy, and scientific feel. Body text font: 'Inter' (sans-serif) for clean, objective readability.
- Minimalist, crisp line icons that align with the high-tech and 'Apple-style' clean aesthetic.
- Spacious, grid-based layout utilizing ample whitespace, inspired by 'Apple-style' minimalism. Key sections feature a 'Prime Asia' dynamic parallax effect for depth and visual interest. Hero section employs left-aligned text with right-aligned product visuals.
- Smooth, deliberate section transitions, subtle scroll-triggered text reveals, and an engaging mouse-follow tilt effect on the 3D product image in the hero section, powered by GSAP.
